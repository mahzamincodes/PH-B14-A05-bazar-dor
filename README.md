# বাজার দর (BazarDor)

BazarDor is a responsive online grocery shopping website that allows users to explore grocery products, browse products by category, view product details, and securely sign in or register using email and password or social login.

## 🛠️ Technologies Used

* Next.js
* React
* JavaScript
* Tailwind CSS
* DaisyUI
* Better Auth
* MongoDB
* React Icons

## ✨ Key Features

1. **Responsive Design:** Provides a smooth browsing experience on mobile, tablet, and desktop devices.
2. **Product Browsing:** Allows users to explore grocery products on the homepage.
3. **Category Navigation:** Enables users to browse products by different categories.
4. **Product Details:** Displays detailed information about individual products.
5. **User Authentication:** Supports registration and login using email and password, Google, and GitHub.
